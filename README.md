# SERV Attendance Management App

## Project Overview
SERV Attendance Management App is a mobile-based attendance management application developed using Flutter. The app helps employees manage attendance and allows admins to monitor attendance-related workflows.

This repository is a demo documentation repository created for portfolio and interview purposes. It includes project overview, contribution details, API testing summary, Firebase flow, and screenshots.

## Project Status
- SERV Attendance Management App was deployed on the Play Store.
- Version 2.0 is currently under development with advanced features.
