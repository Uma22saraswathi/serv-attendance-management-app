# Project Overview

SERV Attendance Management App is a mobile-based attendance management application developed using Flutter. The app helps employees manage attendance and allows admins to monitor attendance-related workflows.

The application includes attendance tracking, employee and admin workflow support, API integration, Firebase database flow understanding, and API testing.

This repository is created as a demo documentation repository for portfolio and interview purposes. It does not include the full project source code because the original project belongs to a team/organization.
