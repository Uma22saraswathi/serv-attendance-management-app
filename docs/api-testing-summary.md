# API Testing Summary

I tested REST APIs using Postman and Swagger for the SERV Attendance Management App.

## API Testing Activities

- Tested GET APIs to fetch data.
- Tested POST APIs to submit data.
- Tested PUT APIs to update data.
- Tested DELETE APIs to remove data.
- Checked request body format.
- Verified response data.
- Checked status codes such as 200, 201, 400, 401, and 500.
- Used Swagger documentation to understand API endpoints.
- Used Postman for manual API validation.

## Tools Used

- Postman
- Swagger
- REST API endpoints
