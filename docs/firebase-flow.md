# Firebase Flow

The SERV Attendance Management App uses Firebase Firestore concepts for storing and managing application data.

## Firebase Understanding

- Understood Firebase Firestore collection and document structure.
- Understood how attendance-related data can be stored.
- Understood frontend-to-backend data flow.
- Understood how APIs connect with Firebase database operations.

## Example Data Flow

1. User performs an action in the Flutter app.
2. The app sends a request to the backend API.
3. The backend processes the request.
4. Data is stored or fetched from Firebase Firestore.
5. The response is sent back to the Flutter app.
6. The app displays the result to the user.
